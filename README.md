# 珍獣発生記念館

2025年刊『ＡＩよみかえ奇譚』を、制作事故ごと展示する2026年のオンライン博物館です。

## 内容

- `index.html` — 展示トップページ
- `style.css` — 展示のデザイン
- `book/` — EPUBから取り出した刊行時の本文、画像、スタイル
- `ai-yomikae-kitan-2025.epub` — 2025年版の原著EPUB

展示解説は原著本文と分けて掲載しています。原著の本文は変更していません。

## ローカルで見る

`index.html` をブラウザーで開いてください。

## GitHub Pagesで公開する

1. このフォルダーの中身をGitHubリポジトリのルートに配置します。
2. リポジトリの **Settings → Pages** を開きます。
3. 公開元に `Deploy from a branch`、ブランチに `main`、フォルダーに `/ (root)` を選んで保存します。
4. 公開されたURLから `index.html` が表示されることを確認します。

公開すると、展示ページだけでなく原著EPUBもダウンロード可能になります。EPUBを含めずサイトだけ公開したい場合は、`ai-yomikae-kitan-2025.epub` をリポジトリに追加しないでください。
